# Requisitos resumidos

## Funcionais

RF01 — Usuário pode pesquisar produtos.
RF02 — Usuário pode filtrar por categoria.
RF03 — Usuário pode visualizar lojas.
RF04 — Usuário pode criar conta.
RF05 — Usuário pode autenticar e encerrar sessão.
RF06 — Administrador pode cadastrar categorias.
RF07 — Administrador pode cadastrar lojas.
RF08 — Administrador/operador pode cadastrar produtos.
RF09 — Administrador/operador pode atualizar produtos.
RF10 — Administrador pode desativar produtos.

## Não funcionais

RNF01 — Frontend e backend devem ser independentes.
RNF02 — Banco não deve ser acessado diretamente pelo frontend.
RNF03 — Senhas não podem ser armazenadas em texto puro.
RNF04 — API deve validar entrada.
RNF05 — API deve possuir limitação de requisições.
RNF06 — Projeto deve funcionar em Windows, Linux e macOS com Node.js.
